Models 8 predictors + ensemble

Each model assigns a probability to all 38 pockets before every spin. The ensemble weights them by recent log-score against a uniform wheel, so a model that does no better than chance loses weight to the uniform baseline. Hit rates are walk-forward: every prediction uses only earlier spins.

Bias lab

The only way history can help is if the wheel itself is biased or consecutive spins are linked. These tests check for that directly. Four tests run on every fair wheel, so a flag needs p below 0.0125 (0.05 ÷ 4).
